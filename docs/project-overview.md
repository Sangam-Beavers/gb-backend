# 프로젝트 개요 (Project Overview)

> Claude Code가 이 프로젝트의 "무엇을, 누구를 위해" 만드는지 이해하기 위한 문서입니다.
> 기술 구조는 [`architecture.md`](./architecture.md), 규칙은 [`conventions.md`](./conventions.md)를 보세요.

---

## 1. 한 줄 요약

**Global Bridge**는 한국에 거주하는 외국인 노동자를 위한 **AI 기반 금융 · 서류 분석 · 커뮤니티 통합 플랫폼**이다.

송금/환전의 어려움, 한국어 문서 이해 문제, 생활 정보 부족 문제를 하나의 서비스에서 해결한다.

---

## 2. 누구를 위한 서비스인가

- 한국에 거주하며 본국 가족에게 송금하는 외국인 노동자
- 근로계약서 · 급여명세서 등 한국어 문서를 이해하기 어려운 사용자
- 비자 · 취업 · 거주 · 생활 정보를 공유하고 싶은 사용자
- 같은 국적/상황의 외국인과 커뮤니티를 형성하고 싶은 사용자

지원 국가/통화는 현재 4개 통화로 고정한다: **KRW, USD, PHP, VND.**

---

## 3. 핵심 기능 3가지

### 3-1. 송금 · 환전 (주머니)

앱 안의 **주머니**(전자지갑)로 여러 통화를 관리하고 충전 · 송금 · 환전한다.

- **충전(가져오기)**: 타행 계좌 → 주머니로 포인트 충전 (※ 구현 수준 2 = Mock API)
- **송금(보내기)**: 두 가지 방식
  - `INTERNAL_TRANSFER` — 앱 사용자에게 이메일(아이디)로 포인트 전송
  - `REMITTANCE` — 외부 타행 계좌로 송금
- **환전**: KRW ↔ (USD/PHP/VND) 실시간 환율 기반. 환전(`EXCHANGE`) / 재환전(`RE_EXCHANGE`)
- 메인 통화 지정(기본 KRW), "지금 나의 원화"(전체 보유 통화의 원화 환산 합계) 표시
- 멱등성 키 + Redis 분산 락으로 이중 송금 방지

→ 상세: [`remittance/`](./remittance/)

### 3-2. AI 서류 분석

한국어 문서를 업로드하면 AI가 위험 조항을 분석하고 모국어로 번역한다.

- 대상 문서: 근로계약서 / 급여명세서 / 고용계약서
- 처리: Pre-signed URL로 사용자가 S3에 직접 업로드 → OCR(VLM) → PII 마스킹 → 법령 RAG 분석 → 번역
- 결과: 위험 등급(LOW/MEDIUM/HIGH), 위험 항목, 급여 요약, 번역 전문
- 첫 화면에 최근 분석 3건 노출, 추가 열람은 월 구독(15,000원)
- 모든 결과에 면책 문구 동반: "AI 분석 결과는 법적으로 완벽하지 않을 수 있습니다. 중요한 판단은 반드시 변호사와 함께하세요."

→ 상세: [`document-analysis/`](./document-analysis/)

### 3-3. 커뮤니티

생활정보 · 비자 · 거주 등 정보를 공유하는 게시판.

- 카테고리: 생활정보 / 직업 추천 / 비자 / 국가별 / 거주 / 질문
- 게시글 · 댓글 · 좋아요(관심글) · 번역 보기
- **인증 배지** — 신분증 인증 사용자는 닉네임 옆에 배지 표시

→ 상세: [`community/`](./community/)

추가로 인증/마이페이지(로그인, 회원가입, 프로필, 신분증 인증, 설정)는 → [`auth/`](./auth/)

## 4. 도메인 용어 사전 (Glossary)

Claude Code는 코드/주석/변수명에서 아래 용어를 일관되게 사용한다.

| 용어 | 영문/코드 | 의미 |
| --- | --- | --- |
| 주머니 | wallet | 사용자의 다중 통화 전자지갑. 사용자당 1개 |
| 포인트 | balance | 주머니 안의 통화별 잔액. **절대 캐싱 금지** |
| 가져오기 | charge | 타행 계좌 → 주머니 충전 |
| 보내기 | transfer | 송금 (앱 내 또는 타행) |
| 앱 내 송금 | INTERNAL_TRANSFER | 앱 사용자 간 포인트 전송 |
| 타행 송금 | REMITTANCE | 외부 은행 계좌로 송금 |
| 환전 | EXCHANGE | 원화 → 외화 |
| 재환전 | RE_EXCHANGE | 외화 → 원화 |
| 견적 | quote | 환전 시 실시간 환율·수령액 산출 결과. 만료 시각 존재 |
| 멱등성 키 | Idempotency-Key | 재시도 중복 실행 방지 헤더 |
| 인증 배지 | is_verified | 신분증 인증 완료 표시 |
| 비버 뱅크 / 쿼카 뱅크 | Beaver/Quokka Bank | 충전/출금 시뮬레이션용 가상 은행(Mock) |

### 사용자 등급

| 등급 | 인증 수단 | 가능 기능 |
| --- | --- | --- |
| 미인증 | 이메일만 | 커뮤니티, 서류 분석 조회 |
| 인증됨 ✓ | 신분증(외국인등록증/여권/본국 신분증) | + 충전 · 송금 · 환전 |

## 5. 주요 화면 (사용 뷰) 구성

Notion API 작업표의 "사용 뷰" 분류 기준이다. 기능 폴더와의 매핑은 아래와 같다.

| 사용 뷰 | 화면 | 관련 폴더 |
| --- | --- | --- |
| 1. 로그인 | 로그인 / 회원가입 / 비밀번호 찾기 | auth |
| 2. 메인 | 주머니 잔액, 환율 | remittance (조회) |
| 3. 송금 | 보내기 흐름 | remittance |
| 4. 환전 | 환전/재환전 흐름 | remittance |
| 5. 충전 | 가져오기, 계좌 등록 | remittance |
| 6. 서류 분석 | 문서 업로드 / 결과 | document-analysis |
| 7. 커뮤니티 | 게시판 | community |
| 8. 마이페이지 | 프로필, 활동 내역, 설정, 인증 | auth |

## 6. 대표 사용자 시나리오

### 시나리오 A — 송금
```
로그인 → 메인에서 주머니 잔액 확인 → '보내기'
→ 송금 방식 선택(앱 사용자 / 타행)
→ 수령인·금액·통화 입력 → 수수료·환율 확인
→ 송금 비밀번호 검증 → 송금 실행 → 완료
```

### 시나리오 B — 서류 분석
```
서류 분석 진입 → 문서 유형 선택 → 사진/파일 업로드
→ (백엔드: Pre-signed URL 발급, 사용자가 S3 직접 업로드)
→ 분석 진행(폴링) → 결과 확인(위험 조항·번역·면책 문구)
→ 저장 또는 커뮤니티 질문 연결
```

### 시나리오 C — 커뮤니티
```
커뮤니티 진입 → 카테고리 선택 → 게시글 목록
→ 상세 보기 → 번역 보기 → 좋아요/댓글
```

---

## 7. 차별점 한 줄 정리

단순 송금 앱이 아니라, **금융 + AI 문서 분석 + 신뢰 기반 커뮤니티**를 외국인 노동자의 실제 생활 맥락에 맞춰 하나로 묶은 서비스다.
